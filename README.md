## Опис проєкту

Цей репозиторій створено в рамках виконання командного завдання з теми "Оброблення текстових файлів мовою Python". Проєкт являє собою консольну програму для створення, обміну даними та читання текстових файлів із використанням безпечного відкриття файлів (конструкція `try-except`).
